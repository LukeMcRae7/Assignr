# Assignr

Student planning for iOS, Android, iPad, and web. Expo 58, React Native, TypeScript, and Supabase.

Use Node 24. `npm install`, then `npm start` or `npm run web`.

For Google sign-in testing in Expo Go, use `npm run start:go` (ngrok tunnel) and allow the callback shown on the sign-in screen in Supabase.

Starts with an empty, persistent local workspace. For Google sign-in and sync, follow [backend setup](supabase/README.md).

`npm test` · `npm run typecheck` · `npm run lint` · `npm run export:web`
